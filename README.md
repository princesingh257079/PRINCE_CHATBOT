# PRINCE_CHATBOT
# 🤖 Simple Chatbot in Python

## 📌 Description

This project is a simple Python chatbot that interacts with users using predefined responses.
It detects keywords in user input and replies accordingly. If no match is found, it gives a default response.

The chatbot also uses randomization to make conversations feel more natural.

---

## 🚀 Features

* 💬 Interactive conversation with user
* 🔍 Keyword-based response system
* 🎲 Random responses for variation
* ❌ Exit option to end chat
* 🤖 Beginner-friendly logic

---

## 🛠️ Technologies Used

* Python
* random module

---

## ▶️ How to Run

1. Install Python
2. Open file in VS Code / Jupyter Notebook
3. Run the script
4. Start chatting with the bot
